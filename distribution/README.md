# Distribution

Ploos AS is the publisher. Retail platforms are distribution channels.

Initial channels:

- Amazon Kindle Direct Publishing (KDP)
- Kobo Writing Life

The canonical publication metadata lives in this repository and is projected into store-specific metadata. Store dashboards must not become the source of truth.

## Artifact model

For normal reflowable books:

- Web/HTML — online edition
- EPUB — primary ebook artifact, qualified for Amazon KDP and Kobo
- PDF — fixed-page digital edition

Store-specific conversions are delivery derivatives, not new source editions.

## Future channels

Apple Books, Google Play Books, library distribution and print may be added without changing the canonical metadata model.
