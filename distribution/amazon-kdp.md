# Amazon Kindle Direct Publishing (KDP)

## Ploos policy

- Canonical author: **Per Gustav Ousdal**
- Canonical publisher/imprint: **Ploos AS**
- Primary reflowable ebook artifact: **EPUB**
- Validate Kindle delivery with Kindle Previewer before release.
- Do not create or archive MOBI as a first-class release format.
- Store-specific metadata must match the canonical publication metadata and cover.
- Kindle/ASIN identifiers are distribution identifiers, not replacements for the Ploos publication registry.
- Print editions, if introduced, receive their own ISBN per format.

## Release gate

1. Canonical metadata validated.
2. EPUB validation passes.
3. Kindle Previewer qualification completed.
4. Cover title/author matches metadata.
5. Store description/categories/keywords reviewed.
6. Rights, territory and price recorded.
7. KDP publication status and ASIN recorded after publication.
